## Module overlap with YOLO26 recipe — summary (`module_overlap.md`)

- **A/OPBR**: orthogonal (recipe has no background-targeted aug). GO, as dataloader transform; benchmark vs OA-Mix-style control.
- **B/PSAS**: partially redundant — `close_mosaic` already schedules aug coarsely and Progressive Loss schedules loss emphasis. Keep only if it beats matched-intensity fixed aug.
- **C/SOFC**: complementary to STAL (label-assignment vs feature-consistency mechanisms). Feasibility improved by evidence: forward outputs already expose neck `feats` with grad — C needs no hooks, ~150–250 LoC trainer subclass, no package fork.

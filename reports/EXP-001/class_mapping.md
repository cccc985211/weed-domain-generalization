## Proposed primary mapping (single class)

| Source class | Maps to | Rationale |
|--------------|---------|-----------|
| CornWeed `weeds` | `weed` (id 0) | direct |
| Weed-crop V2 — all 5 weed species | `weed` (id 0) | species merged; species-level labels retained in manifest for optional secondary analysis |
| CornWeed `maize` | *excluded from labels* (background) | crop-as-context per plan |
| Weed-crop V2 — all 8 crop classes | *excluded from labels* (background) | crop-as-context per plan |

## Preconditions before this mapping is trusted (Step B audit checklist)

1. **Annotation completeness**: verify every image's label file covers all visible
   weeds. If crop boxes are dropped but unannotated weeds exist, they become
   systematic false negatives — the audit must estimate unannotated-weed rate
   on a sampled subset (report only counts, no pixels published).
2. **Illegal coordinates**: out-of-bounds / non-positive / degenerate boxes per
   split; decide clamp-vs-drop rule before conversion (recommend: clamp to
   [0,1], drop if resulting area < 1e-4).
3. **Class-token verification**: confirm actual YOLO label IDs in files match the
   documented schema (don't trust README ordering).
4. **Crop-row labels**: CornWeed has an unused crop-row instance type; ensure it
   is never merged into `weed`.
5. **Unlabeled CornWeed partition (4,981 imgs)**: excluded from supervised
   training and from any labeled metric; candidate only for future
   semi-supervised work — record manifest but do not train on it.

## Secondary option (deferred)

A `crop`/`weed` 2-class variant may be added only if the audit shows label
completeness is high in BOTH datasets; cross-dataset fairness otherwise fails
(CornWeed lacks multi-crop classes). Default stays `weed-only`.
